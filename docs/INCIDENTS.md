# Registro de incidencias de la simulación

Usa **Incidencias** en el panel para registrar tipo, turno, severidad y descripción operativa sin DNI, nombres personales ni preferencias. Puede marcarse RESUELTO con permiso de mesa/operación.

Para acta institucional completa: fecha, responsable, descripción, impacto, contención, resolución, evidencia y aprobación del Comité. Sigue `RUNBOOK.md`; no borres votos para resolver una incidencia.
